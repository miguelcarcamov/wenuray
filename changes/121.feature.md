`wenuray suggest target.ms --imager tclean|pyralysis` writes a recipe derived from the data, each value with its reason as a comment (#121): the fields and spectral windows with data, the reference antenna nearest the array's centre among those with no more flagged data than most, `combine = "spw"` only when one window's phase solution over a scan can't reach twice minsnr, `gaintype = "G"` for amplitudes when one polarization's solution can, an `"auto"` grid, and phases per scan, then repeated at shorter `"auto"` solints, then amplitudes. `--resolve` writes the grid and solints the data support now instead of `"auto"`. Before any model exists, the S/N estimates take the signal from DATA, as the amplitude with the noise taken out, which phase errors don't lower (`read_sample(..., signal_from="data")`).

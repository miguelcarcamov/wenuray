The Pyralysis imager gives each round its file mask (`mask_mode="file"`), as tclean's rounds have theirs. A round's noise is now measured outside the mask, without the source, and its residual inside the mask is measured too, so the warning that the model and gains fit noise there (#119) runs for Pyralysis. Before, the noise was the whole residual's, the source in it, and no in-mask residual was measured, so Pyralysis rounds' rms and peak S/N change.

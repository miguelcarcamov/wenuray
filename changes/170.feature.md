One environment for Wenuray, CASA and Pyralysis. `requirements.txt` pins Wenuray's dependencies and Pyralysis's together, and one conda or micromamba command installs it all: `environment.yml` on CPU, `envs/wenuray-cuda11.yml`, `-cuda12.yml` or `-cuda13.yml` on a GPU, with CUDA and CuPy from conda-forge. Each file stands alone, so it can be downloaded without a clone. The Docker images hold one environment too, and `WENURAY_PYRALYSIS_PYTHON` is no longer needed. The installation guide chooses the GPU file by both the GPU and the driver, and explains the errors of a driver too old for it and of casatools's `manylinux_2_34` wheel.

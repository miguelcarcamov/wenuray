`wenuray suggest target.ms` writes a recipe whose values come from the data, each with a comment saying why (#190): the spectral windows with unflagged data, a reference antenna near the array centre with little flagged data, `minblperant` from the closure minimums, the grid, `nsigma` with the thermal noise from the data, and the steps `Phasecal("inf")`, `Repeat(Phasecal("auto"))`, `AmpPhasecal("auto")`. It reads the data only; `--imager pyralysis` writes a Pyralysis imager. `preflight.read_sample(..., model=False)` samples the noise and the weights without a model. With `--image`, one quick tclean image of `DATA`, cleaned to the noise's expected maximum over the image and with the measurement set left untouched, predicts the solution S/N: the amplitude step stays only if it reaches twice minsnr at solint `"inf"`, and `combine = "spw"` is set when one window falls short of it.
